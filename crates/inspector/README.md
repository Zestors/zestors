# zestors-inspector

[![crates.io](https://img.shields.io/crates/v/zestors-inspector.svg)](https://crates.io/crates/zestors-inspector)

A desktop GUI that visualizes a running [`zestors`](https://crates.io/crates/zestors)
actor tree, by connecting to the introspection endpoints exposed by
[`zestors-api-server`](https://crates.io/crates/zestors-api-server).

Part of the [`zestors`](https://crates.io/crates/zestors) actor framework —
see the [zestors book](https://zestors.github.io/zestors/) for a guided
introduction.
