# zestors-interface

[![crates.io](https://img.shields.io/crates/v/zestors-interface.svg)](https://crates.io/crates/zestors-interface)
[![Documentation](https://docs.rs/zestors-interface/badge.svg)](https://docs.rs/zestors-interface)

`Message`/`Interface`: the vocabulary for defining what a [`zestors`](https://crates.io/crates/zestors)
actor accepts and how it replies.

Part of the [`zestors`](https://crates.io/crates/zestors) actor framework —
see the [zestors book](https://zestors.github.io/zestors/) for a guided
introduction.
